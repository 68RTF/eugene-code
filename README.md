# Eugene Code

Простой сайт для приёма заказов на разработку сайтов.

## Запуск

```bash
npm ci
npm run dev
```

Открой:

http://localhost:3000

## Telegram

Создай `.env.local`:

```env
TELEGRAM_BOT_TOKEN=токен_бота
TELEGRAM_CHAT_ID=твой_chat_id
```

После этого перезапусти локальный сервер.

Для публикации на Netlify добавь `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в переменные окружения сайта: одного файла `.env.local` на твоём компьютере для опубликованной формы недостаточно. Команда сборки задана в `netlify.toml` как `npm run build`.

Нужен Node.js 20.9.0 или новее (см. `package.json`). Без настроенных переменных окружения API заявки вернёт ошибку и не отправит сообщение в Telegram.

У репозитория пока нет лицензии на повторное использование кода.
